# Music Reactivity Modes

Code-grounded reference for the selectable audio-reactive styles. The GUI defines 22 IDs in `src/gui.py:1026-1048`; the visual implementations and aliases are registered in `src/visual_styles.py:3300-3415`. Each engine uses the same `MusicState` analysis, then a selected style turns those features into HSV values. Styles may render one aggregate zone or a spatial field, depending on the device/output path; the descriptions below focus on the shared visual model rather than comparing hardware.

## Shared audio analysis

1. **Frequency bands:** A Hann-windowed 4096-sample FFT is interpolated to 50 band centers, weighted by `(frequency / 60)^0.30`, then normalized per band against an independently decaying peak: `peak[i] = max(level[i], peak[i] * exp(-dt / 2.6))`; `band[i] = clip(level[i] / max(0.015, peak[i]), 0, 1)`. For fast response, normalized bands blend 70% instantaneous FFT and 30% long-window FFT. `src/audio_dsp.py:908-916,983-986`.
2. **Sensitivity:** Each normalized band/feature is multiplied by sensitivity (clamped to 0.1–4.0) then clipped to [0,1]. `src/audio_dsp.py:24-27`.
3. **Kick and transients:** Kick is detected in time domain below 120 Hz; hats and snares use rolling-peak normalization and separate attack/release envelopes. Hats use 10ms attack / 60ms release; snares use 12ms attack / 110ms release. Onset is held with 10ms attack / 240ms release. `src/audio_dsp.py:918-920,988-1053`.
4. **Intensity / tension / impact:** `intensity = clip(0.50*energy + 0.30*kick + 0.20*(1-flatness),0,1)`; `tension = clip(max(0,3.5*energy_trend) + 0.35*centroid_norm,0,1)`; onset impact combines drop strength and onset. `src/audio_dsp.py:1055-1058`.
5. **Quiet and silence:** Music styles render only while audio is genuinely active (not silent and energy ≥ 0.015). Otherwise the renderer fades the last active color/frame over a send-rate-aware interval; it does not repeatedly run the musical style on noise. `src/music_dynamics.py:12-23,38-42`; `src/music_reactive.py:458-478`; `src/music_reactive_l930.py:425-450`.
6. **Color palette:** Styles generally use the analyzer’s harmonic/key-informed palette and interpolate colors in OKLab to reduce hue banding. `src/audio_dsp.py:663-677`; `src/visual_styles.py:33-105`.

## Mode list

For exact selectors, see `src/gui.py:1026-1048`. Implementation mapping is in `src/visual_styles.py:3300-3415`.

1. **Pulse (`pulse`)** — Drum-led travelling ripples. Kicks create outward waves with Gaussian spatial falloff; snares launch sharper counter-pulses, hats add small sparks, and origins can change with phrase/bar position. Build-tension and drop-bloom accents can layer on top. `src/visual_styles.py:512-519,544-640`.
2. **Spectrum (`spectrum`)** — Direct 50-band equalizer. Bands map into a mirrored spatial layout (low frequencies toward the center, high frequencies toward the ends); sub-threshold values below 0.08 are black, otherwise brightness uses `sqrt((raw−0.08)/0.92) × 100 × intensity`. Attack is immediate; decay uses an exponential envelope with `τ=0.075×smoothing/speed`, plus a short peak hold. `src/visual_styles.py:1082-1100,1203-1230`.
3. **Flow (`flow`)** — Harmonic ribbons. Uses smooth energy/band envelopes and palette interpolation to move color waves across zones; energy and harmonic structure shape the wave while smoothing/speed control temporal change. Class/render entry: `src/visual_styles.py:1283,1305`.
4. **EDM Drop (`edm`)** — Riser and drop-focused treatment. Build tension increases/accelerates a spatial pulse; qualified drops add short bloom/flash events with cooldown rather than making every transient a strobe. `src/visual_styles.py:116-168,170-242,1674-1699`.
5. **Chill (`chill`)** — Quiet, warm breathing response. Slow energy/harmonic envelopes move ambient palette and brightness with softer attack/release; it avoids the hard transient emphasis of Pulse/EDM. `src/visual_styles.py:1577,1594`.
6. **Party (`party`)** — High-energy chromatic shifts, with rhythmic/onset-driven color and brightness changes, producing a more active palette rotation than Chill. `src/visual_styles.py:1460,1474`.
7. **Neon Drive (`neon_drive`)** — Synthwave palette, with cyan/magenta accents and kick/snare-directed movement. For one-zone output hue interpolates cyan→magenta by `snare/(kick+snare)` (rest hue 270°); brightness derives from `energy*20 + kick*65 + snare*60`, intensity-scaled and clipped. Spatial output adds position-dependent grid/wave movement and center-kick / wing-snare emphasis. `src/visual_styles.py:2983-3062`.
8. **Sub Blast (`sub_blast`)** — Bass cannon. A center core is `exp(−0.5*(distance/3.8)^2)*smoothed_sub`; a moving shock ring is `exp(−0.5*((distance−radius)/3)^2)*blast_energy`. Hue shifts with distance/ring; brightness combines `70*core + 95*shock`, scales by intensity and drops values under 2.5 to black. Strong bass can desaturate the core toward white. `src/visual_styles.py:3067-3167`.
9. **Vocal Glow (`vocal_glow`)** — Vocal/lead band energy is the mean of normalized bands 12–34 (fallback to `mid`). It is smoothed with 60ms attack / 220ms release; valence slowly shifts the halo center. A palette position combines vocal envelope and valence. `src/visual_styles.py:3172-3207`.
10. **Liquid Groove (`liquid_groove`)** — Fluid, viscous waves. Smoothed bass/energy envelopes act as pressure and downbeat/rhythm modulates moving wave crests; the spatial output is a continuous rather than segmented pulse. `src/visual_styles.py:3235` (renderer follows).
11. **Aurora (`reactive_aurora`)** — Chord/band energy drives a curtain-like field. Multiple smooth spatial waves blend palette colors; musical energy modulates curtain height/brightness rather than assigning one color to every zone. `src/visual_styles.py:2790`.
12. **Twinkle (`twinkle`)** — Sparse transient stars, especially hats/treble. Each event triggers a localized sparkle with its own position, brightness, color, and decay; avoids lighting all zones uniformly. `src/visual_styles.py:2086,2101`.
13. **Bounce (`bass_bounce`)** — Sub-bass controls an elastic fill/bounce. Target fill scales from energy and kick, attacks with τ=15ms and releases with τ=`85ms/speed`; peak position is held and then decays more slowly. Sparse break columns can open on strong snare+hat. `src/visual_styles.py:1886,903-929`.
14. **Center Burst (`center_burst`)** — Bass events expand from the center toward both ends. Distance from the center sets the wave envelope and palette/brightness; onset and kick drive the burst. `src/visual_styles.py:1967,1990`.
15. **Segmented VU (`segmented_vu`)** — Five 10-zone instrument pods. Per-pod energy is `(0.65*energy + 0.35*kick)*10*intensity`; it maps to a filled extent and a held/decaying peak. In the spatial style, pods expand from their centers, and a break pattern adds dark gaps. `src/visual_styles.py:820-829,903-940`; mapping `:3312,3381-3384`.
16. **BPM Resonator (`bpm_resonator`)** — Tempo/beat-phase-locked pulses; beat phase and bar position place repeating resonant accents, while energy and kick set amplitude. Confidence-aware BPM and phase originate in the shared tracker. `src/visual_styles.py:2544`; analyzer tracker `src/audio_dsp.py:255-296`.
17. **Acoustic String (`acoustic_string`)** — Modeled plucked-string response. Pluck/transient strength excites a string-like spatial resonance that rings down over time; pitch/chroma influence the note color. `src/visual_styles.py:2217,2230`.
18. **Hydro Acoustic (`hydro_acoustic`)** — Frequency/pressure features create waterfall-like descending or flowing bands; smoothed energy controls their amplitude and decay. `src/visual_styles.py:2316,2328`.
19. **Melodic Contour (`melodic_contour`)** — Tracks melodic/pitch contour into a moving line; pitch/chroma and valence shape the hue path, with energy controlling line intensity. `src/visual_styles.py:2486,2499`.
20. **Lo-Fi Vinyl (`lofi_vinyl`)** — Warm ambient palette with slow drift/flutter and soft energy response; avoids sharp full-field transients. `src/visual_styles.py:2418,2439`; factory maps `lofi_vinyl` to this style `:3318,3335-3336`.
21. **Chain Reaction (`chain_reaction`)** — An initial musical event triggers a bounded cascade of spatial events. Each event’s energy/decay can trigger nearby follow-on points, creating stochastic lightning movement instead of unrelated per-zone random flicker. `src/visual_styles.py:2653`.
22. **Movie Sync (`movie`)** — Screen-derived colors are the base; audio contributes restrained vocal/theme swells and bass flare. For the 50-zone room-fill field, each output zone maps to a screen-column position and applies a 5-tap Gaussian kernel `[0.061,0.242,0.383,0.242,0.061]` to hue/saturation/value, then blends with the room base. Audio swell has τ=400ms; screen identity stays primary. `src/visual_styles.py:314-350,441-489`.

## Naming and aliases

The desktop GUI’s `segmented_vu` maps to the registry’s `segmented` instance. Other registry aliases include `club`→Party, `drop`/`edm_drop`→EDM, `synthwave`/`synthwave_pulse`→Neon Drive, `bass_cannon`→Sub Blast, `vocal`→Vocal Glow, `groove`→Liquid Groove, `aurora`→Aurora, `sparkle`→Twinkle, `bounce`→Bounce, `burst`→Center Burst, `resonator`→BPM Resonator, `acoustic`/`string`→Acoustic String, `hydro`→Hydro Acoustic, `melodic`/`contour`→Melodic Contour, `lofi`→Lo-Fi Vinyl, and `random_chain`/`chaos`→Chain Reaction. `get_visual_style` falls back to Pulse for unrecognized names. `src/visual_styles.py:3330-3415`.

> **Debugging note:** Several descriptions above summarize code intent where this inventory pass only verified class/render entry points rather than every internal operation. Before using a mode’s listed behavior as a bug diagnosis, inspect that renderer’s full implementation and tests; the cited lines identify the relevant source to trace.
